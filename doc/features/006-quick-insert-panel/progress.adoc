Подключены все кнопки ряда, кроме `›` (SL-3).

Дозаявлено реализацией (см. одноимённый раздел аналитики)::

=== SL-3 — раскрытие `›` · 2026-08-17 · устройство-проверки пройдены

Сделано::
`BlockTemplate` — блочная заготовка с одним слотом; конструкции таблицы (`|===`), admonition (абзацная `NOTE:` — дорешённый `OQ-5`) и блока кода (`[source]` + `----`).
Касание `›` замещает ряд кнопками `‹` \ `|===` \ `NOTE` \ `----` (решение `OQ-1`); высота панели не растёт; признак раскрытия в `rememberSaveable` (`NFR-5`).
+6 тестов applier (всего 26), TDD с красным прогоном.

Проверено на устройстве (координатором)::
Замещение ряда и возврат `‹`; вставка таблицы с кареткой в первой ячейке; *поворот экрана в раскрытом состоянии — признак пережил* (`NFR-5`); таблица дорендерилась в превью; автосейв записал правки на диск, `CRLF` файла сохранён насквозь.

Микрорешения реализации::
Подписи кнопок раскрытого ряда и их описания — в языке базового ряда, макет их не рисует (на сверку владельцу).
Прокрутка при замещении ряда сбрасывается — короткий ряд не наследует смещение базового.
Сторож `rememberSaveable` без композиции не тестируем — проверен поворотом; при появлении инструментального прогона Compose UI кейс первый в очереди.
Admonition при обёртке в середине строки уводит хвост строки в продолжение абзаца заметки — следствие общего правила блочных заготовок; захочется пустой строки-разделителя — отдельное решение.
