== Записи

[NOTE]
Записи `SL-1` и `SL-2` восполнены задним числом: правки журнала при их закрытии молча не применились (маркер вставки не совпал с текстом файла), и это заметил агент следующего слайса.
Содержимое восстановлено из сообщений коммитов и отчётов — они и были первоисточником.

=== SL-1 — каркас экрана · 2026-08-17

Единственный `TextFieldState` через `rememberSaveable`; app bar с именем файла и меткой «ИЗМЕНЁН · НЕ СОХРАНЁН» из модели; вкладки; пустое состояние; автоподъём документа после перезапуска.
Проверено на устройстве восемью сценариями со снимками, включая гашение метки после реальной записи на диск.
Запись заработала раньше плана — план был старше шва записи; политика на документ живёт в дочернем scope, хвост записи не утекает при смене файла.
Код лёг в пакет `screen/` вместо `ui/editor` из первоначальных `:targets:` — зона `ui/` принадлежала слайсу видимого окна; `:targets:` поправлены.

=== SL-2 — живое превью · 2026-08-17

`PreviewPipeline` по образцу `AutosaveRunner`: экземпляр на документ в его дочернем scope, отмена доезжает до прерывания движка; сигнал видимости «вкладка ∧ документ ∧ передний план», фон глушит движок.
Главная находка интеграции: `WebView` уничтожался с уходом панели из композиции, убивая прокрутку, — починено парковкой за краем экрана; alpha/zIndex отвергнуты, невидимая платформенная вью ловит касания.
Пробел спеки закрыт дозаявленным `TC-19` (отказ рендера на экране).

=== SL-3 — папка, плашка записи, фон · 2026-08-17 · закрыт, устройство-проверки пройдены

Сделано::
Открытие папки, список `.adoc` с тремя пустыми состояниями, отказ открытия возвращает к списку с уведомлением; плашка отказа записи с «ПОВТОРИТЬ» в языке плашки рендера; запись при уходе в фон по edge-триггеру.
Источник картинок дерева прокинут до превью.
18 тестов модели, `check` зелёный.

Стыковка, потребовавшая обёртки::
`AutosaveRunner` отдаёт политике только факт отказа и теряет тип ошибки — текст для плашки перехватывается обёрткой шва на границе зоны экрана.
Чище было бы отдавать ошибку из runner-а; кандидат в мелкий слайс фичи 004.

Придумано вне макета::
Кнопка «СМЕНИТЬ» в шапке списка (иначе смена папки недоступна до меню) и тексты пустых состояний.
Debug-диагностики для проверок: потеря права и перечень разрешений по флагам запуска, за гейтом debuggable.

Устройство-проверки (координатором, по сценарию слайса)::
`TC-27` фичи 004 пройден целиком: список показывает только `.adoc` (фильтр работает), запись под правом дерева ложится в файл на диске, `persistedUriPermissions` — ровно одна запись (дерево, r+w), отзыв права даёт штатное «Папка недоступна… выберите заново».
`TC-34` фичи 003 пройден: картинка рядом с документом видна в превью, попытка выйти из дерева (`../outside.png`) — сломанная иконка, файл не отдан.
Плашка отказа записи руками не спровоцирована: диагностический флаг доставляется только холодным стартом, а холодный старт с отозванным правом уводит в список раньше открытия документа.
Плашка остаётся закрытой юнит-тестами; спровоцировать её вживую получится при отказе реальной записи (нет места), и это честно записано.

=== SL-4 — меню документа и клавиатура · 2026-08-17 · этап E1 закрыт

Сделано::
Меню документа в app bar: «Отменить»/«Повторить» (приглушены при пустой истории), «Открыть папку…» тем же потоком, что «Сменить», «Повторить запись» — только пока отказ актуален.
Undo/redo с аппаратной клавиатуры: `Ctrl+Z` / `Ctrl+Shift+Z` через `onPreviewKeyEvent` на корне, событие поглощается против двойной отмены.
Единая точка `undoRequested`/`redoRequested` в модели — меню и клавиатура зовут одно и то же, расхождение поля с превью невозможно по построению.
Временные поверхности `RenderSkeleton` и `DocumentAccessScreen` удалены; доля общего кода выросла до ~84 %.
338 тестов, `check` зелёный; смоук на устройстве пройден (меню, оба сочетания, отмена диалога папки).

Закрывает и слайс SL-5 фичи 004::
Одна работа, не две — по координации плана; запись в журнале 004.

Придумано вне макета (макет «02» рисует только кнопку меню)::
Панель меню — свой `Popup` на токенах (raised, рамка, квадратные углы, Barlow Condensed прописными), не Material `DropdownMenu` — тот несёт скругления.
Кнопка меню — три квадратные точки из боксов до появления набора иконок; тексты пунктов; ширина по содержимому (`IntrinsicSize.Max`) — дефект первой сборки с растянутой панелью пойман смоуком.
Иконка-переключатель превью из макета опущена: дизайн-половина `OQ-4` не отвечена, дублировать вкладку по умолчанию не стали — вопрос владельцу остаётся открытым.

Debug-хуки остались хуками::
Проверки скриптуются из adb без касаний, а меню продукта не носит отладочных пунктов даже за гейтом debuggable; требование «проверочные возможности остаются» выполнено хуками.
