== Критерии слайса

Слайс годен, только если выполнено *всё*:

Вертикальный:: проходит сквозь слои до наблюдаемого результата.
Трассируем:: колонка «Закрывает» непуста и ссылается на существующие `FR`, `NFR` или `TC` из `analysis.adoc`; исключение — спайк SL-0, закрывающий гипотезы разведки.
Демонстрируем:: есть, что показать: действие в приложении, тест, замер.
Обозрим:: умещается в один рабочий сеанс, ориентир 1–5 файлов правки.
Независим по входу:: зависит только от уже закрытых слайсов и решённых вопросов, не от будущих.
С DoD:: пройден цикл закрытия (`reference/closing-loop.md`): тесты по перечисленным TC зелёные, ревью без принятых находок, документация обновлена, стиль сверен, коммит с идентификатором слайса.

== Границы работ

Действуют на все слайсы фичи; базовый набор — в xref:../../development-rules.adoc[правилах разработки], здесь уточнения под фичу.

✅ Всегда:: Тест раньше кода; логика и модели — в `commonMain`; `commonTest` — на фейке интерфейса, JGit — только в device-тестах; `security-review` в ревью слайсов, касающихся секретов и сети.
⚠️ Спросить:: Добавление зависимости сверх JGit и sshd; любое новое сетевое обращение вне явных операций пользователя; изменение решений видения (mine/theirs, JGit, пост-MVP); правка `US-E5-01` по итогам `OQ-1`.
🚫 Никогда:: Секреты, URL с кредами и содержимое ключей — в логи, настройки или тестовые фикстуры; типы JGit в `commonMain`; сетевые обращения из автоматических тестов; коммит при красном прогоне; правка вне `targets` фичи.

== Риски и точки перепланирования

* [x] *JGit 7.x не заводится на ART* (H1) — *снят спайком SL-0*: работает, откат на 6.x не нужен (xref:research.adoc#spike-e0-h1[факты]).
Взамен всплыл новый риск ниже — конвейер device-тестов.
* [x] *Push из shallow не проходит* (H2) — *снят спайком SL-0 для клиентской стороны* (xref:research.adoc#spike-e0-h2[факты]); unshallow-fetch не нужен, серверные политики GitHub/GitLab проверяются ручными кейсами E2.
* *Device-тесты Git не собираются в `shared/src/androidDeviceTest`* — установлено спайком SL-0: конвейер дексации device-тестов KMP-модуля падает на Java records из JGit 7.x (xref:research.adoc#spike-e0-build[точная ошибка]).
До починки AGP Git-device-тесты кладутся в `androidApp/src/androidTest`; при активации E1 уточняется `:targets:` аналитики (SL-2).
* *OQ-1 решён в сторону `DocumentsProvider`* → объём E1 растёт на отдельный компонент → SL-4 расщепляется, `US-E5-01` уточняется.
* *Память: клон реального репозитория валит устройство* → узнаём на спайке или первом device-прогоне → вводим настройку `streamFileThreshold`/`WindowCache` в реализации и порог размера в требования.
* *MINA sshd тянет неожиданные зависимости в APK* → узнаём при подключении в E4 → замер размера APK, при неприемлемом росте — пересмотр ADR-007.
