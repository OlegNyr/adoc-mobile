== Границы работ

Базовый набор — в xref:../../development-rules.adoc[правилах разработки], здесь уточнения под фичу.

✅ Всегда:: тест раньше кода; значения берутся из xref:../../design/design.adoc[описания дизайна] и только оттуда; роли именуются по-русски в документации и латиницей в коде.

⚠️ Спросить:: любое значение, которого нет в описании дизайна (в том числе светлые оттенки); добавление зависимости; изменение состава ролей палитры.

🚫 Никогда:: литерал цвета в обход роли; скругление, подавленное по месту вместо темы; выдумывание значений светлой темы; коммит при красном прогоне.

== Риски и точки перепланирования

* Ресурсы шрифтов в Compose Multiplatform могут потребовать отдельного плагина ресурсов → выяснится на SL-2; если так, слайс расширяется настройкой сборки, а не откладывается.
* Проверка «нет литералов цвета» (`TC-8`) может не собраться дешёвым тестом → тогда переезжает в CI отдельным шагом, но не отменяется.
