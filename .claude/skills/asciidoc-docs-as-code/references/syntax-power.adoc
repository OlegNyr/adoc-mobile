= AsciiDoc: то, чего нет в Markdown
:toc: left
:toclevels: 2
:icons: font
:experimental:
:source-highlighter: highlight.js

Файл написан на AsciiDoc намеренно: его можно собрать и посмотреть, как
выглядит каждый приём. Базовый синтаксис (заголовки, списки, ссылки) здесь
пропущен — он совпадает с ожиданиями.

== Атрибуты

Атрибуты — переменные документа. Объявляются в шапке или по ходу текста,
подставляются фигурными скобками.

[,asciidoc]
----
:spring-boot-version: 3.5.0
:repo-url: https://git.corp.local/cc/platform

Проект собран на Spring Boot {spring-boot-version}, исходники — {repo-url}.
----

Встроенные, которые стоит знать:

[cols="1,3", options="header"]
|===
| Атрибут | Что делает

| `{docfile}` / `{docdir}`
| Путь к текущему файлу и его каталогу. Незаменим для ссылки «править здесь».

| `{docdate}` / `{localdate}`
| Дата последнего изменения / дата сборки.

| `{empty}`
| Пустая подстановка. Спасает, когда нужно склеить конструкции без пробела.

| `{nbsp}` `{zwsp}`
| Неразрывный и нулевой пробел. `{nbsp}` — между числом и единицей: 200{nbsp}мс.

| `{counter:seq}`
| Автонумерация чего угодно: примеров, шагов, требований.
|===

Условная логика:

[,asciidoc]
----
ifdef::internal[Только для внутренней версии.]
ifndef::confluence[]
Этот блок не поедет в Confluence.
endif::[]
ifeval::[{java-version} >= 21]
Доступны виртуальные потоки.
endif::[]
----

== Include: главная суперсила

=== По тегам

В исходнике:

[,java]
----
// tag::consumer[]
@KafkaListener(topics = "dialog.event.v1")
public void onEvent(DialogEvent event) { … }
// end::consumer[]
----

В документе:

[,asciidoc]
----
include::{sourcedir}/ChatConsumer.java[tag=consumer,indent=0]
----

`indent=0` нормализует отступ. `tags=a;b;!c` — несколько тегов, восклицательный
знак исключает вложенный.

=== По строкам

[,asciidoc]
----
include::app.yml[lines=12..24]
include::app.yml[lines=1..5;30..-1]
----

Хрупко: сдвинется код — сдвинется include. Используй только для файлов,
которые не меняются (лицензии, фиксированные конфиги).

=== Уровень вложенности

[,asciidoc]
----
include::_partials/warning.adoc[leveloffset=+1]
----

`leveloffset` сдвигает заголовки внутри включаемого файла — один партиал
работает и как раздел, и как подраздел.

== Callouts

Аннотации к коду по номерам. В блоке — комментарий с `<1>`, под блоком —
список.

[,java]
----
@Bean
ConcurrentKafkaListenerContainerFactory<String, DialogEvent> factory() {
    var f = new ConcurrentKafkaListenerContainerFactory<String, DialogEvent>();
    f.setConcurrency(3);                              // <1>
    f.setCommonErrorHandler(new DefaultErrorHandler(  // <2>
        new DeadLetterPublishingRecoverer(template),
        new FixedBackOff(1000L, 2L)));
    return f;
}
----
<1> Должно совпадать с числом партиций топика, иначе часть потоков простаивает.
<2> Две попытки с паузой в секунду, дальше — в DLQ. Значения подобраны под SLA
    оператора: суммарная задержка не превышает 3{nbsp}с.

Работает и в YAML/XML/bash — комментарий подставляется под синтаксис языка.

== Блоки

[cols="1,2,3", options="header"]
|===
| Разделитель | Тип | Когда

| `----`
| listing / source
| код, вывод консоли

| `....`
| literal
| текст «как есть», без подсветки

| `====`
| example
| пример целиком: код + пояснение + вывод

| `****`
| sidebar
| врезка сбоку, база для кастомных адмонишенов

| `--`
| open
| контейнер под роль, когда нужен просто `div`

| `____`
| quote
| цитата с автором

| `++++`
| passthrough
| сырой HTML — использовать в последнюю очередь
|===

Именованный пример со счётчиком:

[,asciidoc]
----
.Пример {counter:example}: ретрай с backoff
[example]
====
Содержимое.
====
----

== Таблицы

[,asciidoc]
----
[cols="2,1,1,4", options="header", stripes=even, %autowidth.stretch]
|===
| Свойство | Тип | Дефолт | Описание

| `cc.kafka.retry.max-attempts` | int | `3`
| Число попыток до DLQ.

4+| Строка на всю ширину — так оформляются группы свойств.
|===
----

Приёмы, которые почти никто не использует:

* `a|` вместо `|` — ячейка с полноценным AsciiDoc внутри (списки, код).
* `2+|` — объединение колонок, `.2+|` — строк.
* `[cols="1,1"] .Заголовок` — подпись над таблицей, попадает в список таблиц.
* `include::data.csv[]` внутри `[format=csv]` — таблица из CSV-файла, который
  генерится скриптом.

[,asciidoc]
----
[format=csv, options="header", cols="1,1,2"]
|===
include::{datadir}/error-codes.csv[]
|===
----

Так справочник кодов ошибок генерится из enum и не расходится с кодом.

== Ссылки и якоря

[,asciidoc]
----
[#retry-policy]
=== Политика ретраев

См. <<retry-policy>> или <<retry-policy,политику ретраев>>.
xref:how-to/kafka.adoc#retry-policy[Ретраи]        — на якорь другой страницы
link:https://example.com[Внешняя ссылка^]          — ^ открывает в новой вкладке
----

Явные якоря (`[#id]`) обязательны для разделов, на которые ссылаются извне:
автогенерируемый id меняется вместе с заголовком и ломает чужие ссылки.

[IMPORTANT]
====
Отдельная причина для русскоязычной документации: при `:idprefix:` и
`:idseparator: -` Asciidoctor генерирует якоря прямо из заголовка, то есть
кириллицей — `#подключение`. В адресной строке это превращается в
`#%D0%BF%D0%BE%D0%B4...`, такую ссылку неудобно отправлять в чат и невозможно
прочитать глазами. Ставь латинские якоря руками для всех разделов, на которые
будут ссылаться: `[#getting-started]`.
====

== Списки

[,asciidoc]
----
Термин:: Определение — список определений, идеален для глоссария.
Второй термин:: Ещё определение.

. Первый шаг
. Второй шаг
+
--
Абзац, код или таблица, принадлежащие второму шагу.
Символ `+` привязывает блок к пункту, `--` объединяет несколько блоков.
--
. Третий шаг

* [ ] Невыполненный пункт
* [x] Выполненный
----

[,asciidoc]
----

pass:[<kbd>raw</kbd>]                     — точечный passthrough
+не обрабатывать {атрибуты}+              — inline literal
----

== Что не стоит использовать

* `+++<div>+++` для вёрстки — сломается в PDF и Confluence. Используй роли.
* Ручную нумерацию разделов — есть `:sectnums:` и `:sectnumlevels:`.
* `[cols]` без явных ширин в справочниках — таблица разъедется.
* Абсолютные пути в `include::` — сборка перестанет быть воспроизводимой.
