== Что это такое

Платформа принимает обращения из чата на сайте, мобильного приложения,
мессенджеров и телефонии, приводит их к единой модели диалога и маршрутизирует
на свободного оператора с учётом навыков, языка и нагрузки.

[.admonition.experimental]
****
Канал видеозвонков доступен с версии {project-version} под флагом
`cc.channels.video.enabled`. API может измениться в следующем минорном релизе.
****

== Первый обработчик событий

.ChatConsumer.java — приём события диалога
[,java]
----
@Component
class ChatConsumer {

    @KafkaListener(topics = "dialog.event.v1", concurrency = "3")  // <1>
    void onEvent(DialogEvent event, Acknowledgment ack) {
        dialogs.apply(event);                                       // <2>
        ack.acknowledge();                                          // <3>
    }
}
----
<1> Значение должно совпадать с числом партиций топика: лишние потоки простаивают,
    недостающие — упираются в лаг.
<2> Применение события идемпотентно по `event.id`, повторная доставка безопасна.
<3> Подтверждение вручную: при `AckMode.MANUAL` офсет двигается только после
    успешного применения.

[.admonition.gotcha]
****
`@KafkaListener` с `concurrency > 1` не гарантирует порядок между партициями.
Если логика зависит от порядка событий одного диалога, ключ сообщения обязан
быть `dialogId` — иначе события разъедутся по партициям.
****

== Ключевые настройки

[cols="3,1,1,4", options="header", stripes=even]
|===
| Свойство | Тип | Дефолт | Что делает

| `cc.kafka.retry.max-attempts`
| int
| `3`
| Число попыток обработки до отправки в DLQ.

| `cc.kafka.retry.backoff`
| Duration
| `1s`
| Пауза между попытками. Суммарная задержка не должна превышать SLA оператора.

| `cc.routing.skill-match`
| enum
| `STRICT`
| `STRICT` — только точное совпадение навыка, `RELAXED` — деградация до общей очереди.

4+| Полный список — в xref:reference/config.adoc[справочнике конфигурации].
|===

[.admonition.perf]
****
`cc.routing.skill-match=STRICT` при узком наборе навыков даёт очередь на
входе: обращение ждёт конкретного оператора вместо любого свободного.
На проде с 40+ операторами разница в p95 времени ожидания — около 12{nbsp}с.
****

[.admonition.security]
****
Токен оператора живёт 15 минут и не должен попадать в логи и трассировки.
Маскирование проверяется тестом `SecurityFilterTest#tokenIsMasked` — при
добавлении новых логгеров тест обязателен.
****
